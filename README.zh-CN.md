# Meshwork

[English](README.md) · [设计文档](docs/design.zh-CN.md)

Meshwork 是一个正在设计的桌面任务工作台，供人和 AI Agent 一起完成任务。你可以为经常做的一类工作创建 Bot，定义它应该遵循的步骤，再把任务交给它。Bot 负责在人和 Agent 之间交接，任务卡集中记录决定、进度和交付物。

## 个人 Bot

在自己的桌面端创建 Bot，让它围绕你的项目和文件执行工作流。例如，开发 Bot 可以分步调用 Codex 分析需求、实施变更并验证结果。Meshwork 在你的电脑上运行 Codex，再把执行结论、变更文件和测试结果带回任务卡。

## 项目 Bot

为团队创建项目，邀请成员用各自的账号加入，并集中管理仓库、文档、任务和交付物。项目 Bot 归项目所有，工作流可以把步骤派给真实成员或 Agent，并通过可配置的触发节点启动或继续任务。

例如，同一套代码审核流程可以接收 GitHub PR 或 GitLab MR 事件，触发节点可以选择多个仓库。流程派发 Codex 审核指定版本，将发现保存到项目里，也可以先交给成员确认，再由独立的步骤将报告发布回来源平台。其他流程也能通过手动触发或 Webhook 处理仓库之外的任务。

## 任务在哪里执行

桌面端在本机运行个人工作流，设备所有者启用项目访问后也可以执行团队任务。Linux 机器可以运行无界面的 Meshwork 执行程序，执行相同的步骤。团队服务端负责协调项目任务，在各账号之间同步任务上下文和结果。Codex 使用执行机器上的登录态和工作区。

## 项目进度

Meshwork 目前处于设计阶段。首版拟覆盖本地个人工作流，以及包含人工交接、事件来源可配置的团队代码审核工作流。架构、执行方式和首版验收条件见[设计文档](docs/design.zh-CN.md)。
